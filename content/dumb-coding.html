Dumb Coding

I code with AI most of the time. To the point that I'm afraid I will forget how to code.

I have also not spent time trying to learn any new language, and I think there is value in learning a new language. They work in different ways and they can expand the way you think about code.

Additionally, LLMs are very good at coding in any language. This makes it easier to use the "right language" for the type of application that you are trying to use. Yet, to unlock this skill I feel that you should have some notion of how different languages work. Hopefully this experiment will help with both.

I'm starting with writing a program that calculates the shortest path between two nodes in a graph using Rust! Wish me luck
